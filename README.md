# shorts-studio-releases

This public repository holds **Shorts Studio** Windows installer releases only: the NSIS installer, `latest.yml`, and the blockmap that the in-app updater reads.

The app source lives in the private repository [offthexio/viral-video-team](https://github.com/offthexio/viral-video-team). This feed is public so [electron-updater](https://www.electron.build/auto-update) can check for updates without putting a GitHub token in the app.

Do not store source code, API keys, or signing certificates here.
